Bisse du Ro

Un canal médiéval accroché à la falaise au-dessus de Crans-Montana. Suis l’eau, résous les énigmes, débloque les vues drone.

Départ Plans-Mayens Commune Icogne Durée ≈ 3 h selon la boucle Rallye 5 postes, dès 8 ans

Le rallye du Ro

Cinq postes le long du bisse. À chaque bonne réponse, une goutte se remplit et une vue drone de l’endroit se débloque. Les cinq gouttes donnent le code final à présenter à la buvette.

    Pour l’office du tourisme

    Ce carnet est un prototype. Le même moteur s’applique à toutes les randonnées d’un secteur.

    Sans application

    Un lien ou un QR code au départ du sentier. S’ouvre dans le navigateur, fonctionne ensuite hors ligne.

    Familles

    Le rallye transforme la balade en jeu. Les enfants vont jusqu’au bout.

    Commerces partenaires

    Le code final ramène les visiteurs à une buvette ou un commerce du village.
